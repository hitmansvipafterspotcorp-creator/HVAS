# Phaser 4.1.0 Brawler Module Map

Use this map when creating or refactoring files. Keep systems independent and testable.

- InputBuffer: timed input queue and combo matching.
- DepthGate: floor-projected hit validation.
- CombatSystem: active hitboxes and hurtboxes.
- WaveDirector: spawns and camera lock gates.
- CrowdControl: rush-token and spacing manager.
- HitStop: pauses actors briefly while allowing VFX/audio.
