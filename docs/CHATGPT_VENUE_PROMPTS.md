# HVAS — ChatGPT Prompts to Re-Do Every Venue (OUTSIDE + INSIDE)

One prompt per game surface. **Save each with the exact filename shown** and
drop it in `assets/venues/` on GitHub — the game auto-loads by that name.

## Rules (read once)
- **Do it all in ONE ChatGPT chat.** After the first image, begin later prompts
  with *"Same exact art style, palette, and lighting as the previous image."*
- **Size:** ask for **1536×1024 landscape** every time (ChatGPT's widest).
- **CRITICAL — no dev art:** every image must have **NO text labels, NO written
  words, NO dashed lines / arrows / route paths, NO zone legends, NO grid, NO
  white margins or borders.** The art must **fill the whole frame edge to edge.**
  (The only allowed text is a venue's own neon **sign** on an exterior.)
- Spell venue names exactly. Never "Circle K", never "Palace Saloon".

---

> Flat side-on elevation view (straight-on, eye level, NO isometric tilt, NO

## INSIDE BLOCK — paste in every INTERIOR prompt
> Top-down 3/4 overhead view like a classic top-down RPG (think Pokémon /
> Stardew Valley / Zelda) — camera looking down at the room floor. The center is
> open, walkable floor; bar, furniture, and props sit around the edges. Whole
> room fills the frame, no border. 1536×1024 landscape.
