UI_sliced_clean_v5

Use the by_type folders first:
- by_type/screens: larger UI screens and assembled examples
- by_type/buttons: button-sized controls and chips
- by_type/cards: pass cards, panels, timers, widgets, and large framed assets
- by_type/icons: small icons, digits, badges, and small tokens
- by_type/components: other usable components

The sources folder keeps crops grouped by original sheet.
The discarded_candidates folder contains labels, guides, tiny text/noise, and other candidates that were filtered out so nothing is permanently lost.

Contact sheets are in contact_sheets for review before implementation.
Original assets were not modified.
